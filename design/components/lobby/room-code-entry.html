대기실 · 기능 ② · 친구모드 (참가자)

방코드 입력 + 입장

친구가 알려준 네 글자를 넣고 방에 들어갑니다. ①과 구조는 같지만 결정적으로 다른 점이 하나 있습니다 — 성공하면 이 화면에 머무르지 않고 게임 화면으로 넘어갑니다. 그래서 "통과했다"는 표시는 아주 잠깐만 보입니다.

상태 6종

비어 있음 → 아직 덜 찼음 → 확인하는 중 → 없는 방 / 꽉 찬 방 / 입장. 마지막 두 칸은 둘 다 실패지만 사용자가 다음에 할 일이 다릅니다.

1 · 기본 (비어 있음)

친구에게 받은 네 글자를 넣어주세요

빈 칸 네 개가 몇 글자를 넣어야 하는지를 그 자체로 알려줍니다. 긴 입력칸 하나였다면 몇 자인지 따로 적어줘야 했습니다.

2 · 아직 덜 찼음

2 / 4

아직 채우는 중입니다. 여기서 빨간 오류를 띄우면 안 됩니다. 아직 잘못한 게 아니라 그냥 안 끝난 것이니까요. 버튼만 꺼둡니다.

3 · 확인하는 중

그런 방이 있는지 알아보는 중이에요

네 글자가 다 찼고, 답을 기다립니다. 이때 칸도 같이 잠급니다. 기다리는 동안 글자를 고치면 방금 물어본 코드와 화면에 보이는 코드가 달라집니다.

4 · 없는 방코드

! 그런 방이 없어요. 코드를 다시 확인해 주세요

오타이거나, 방이 이미 닫혔습니다. 칸이 한 번 좌우로 흔들리고 곧바로 비워지며 첫 칸에 커서가 갑니다 — 다시 치는 것 말고 할 일이 없으니 그 준비를 대신 해줍니다.

5 · 꽉 찬 방 제안

! 이미 두 명이 게임 중인 방이에요

기획에 없던 칸입니다. 코드는 맞았는데 자리가 없는 경우입니다. 4번과 달리 다시 쳐도 소용이 없어서, 같은 빨간 문구로 뭉뚱그리면 사용자는 오타인 줄 알고 계속 다시 칩니다. 필요 없으면 빼겠습니다.

6 · 입장 (곧 넘어감)

✓ 방을 찾았어요. 들어가는 중…

잠깐 초록으로 바뀌었다가 게임 화면으로 넘어갑니다. 바로 넘겨버리면 사용자는 방금 뭐가 일어났는지 모른 채 화면이 튄 것처럼 느낍니다. 이 짧은 순간이 그 설명입니다.

눌러보기

칸에 직접 쳐보세요. 한 글자 넣으면 다음 칸으로 넘어가고, 지우면 앞 칸으로 돌아갑니다. 네 글자를 붙여넣어도 됩니다. 모양만 확인하는 미리보기입니다 — 어디에도 연결되어 있지 않습니다.

정해둔 규칙

숫자와 문구는 여기에 적힌 대로 화면에 박아둡니다. 바꾸려면 이 표부터 고칩니다.

항목값왜
코드 길이4자친구에게 말로 불러줄 수 있어야 합니다. 길면 못 외웁니다.
쓰는 글자영문 대문자 + 숫자소문자로 쳐도 자동으로 대문자가 됩니다. 대소문자를 구별하면 말로 알려줄 때 틀립니다.
빼는 글자O 0 I 1말로 불러줄 때 가장 많이 틀리는 짝입니다. 아예 안 쓰면 헷갈릴 일이 없습니다.
한 글자 넣으면다음 칸으로 자동 이동네 번 클릭하게 만들 이유가 없습니다.
지우면앞 칸으로 이동고칠 때 자연스럽게 뒤로 돌아가야 합니다.
붙여넣기네 칸에 나눠 채움친구가 채팅으로 보낸 코드를 그대로 붙일 수 있어야 합니다.
버튼 켜짐네 칸이 다 찼을 때만덜 찬 상태에서 누를 수 있으면 헛수고를 시킵니다.
확인하는 동안칸·버튼 모두 잠금물어본 코드와 보이는 코드가 달라지면 안 됩니다.
