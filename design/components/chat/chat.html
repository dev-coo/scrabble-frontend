채팅 모듈

대기실과 게임 화면이 같은 한 벌을 나눠 씁니다. 화면마다 따로 만들면 나중에 말풍선 하나 고치는 데 두 군데를 손대야 하고, 한쪽만 고치면 두 화면이 서로 달라집니다.

눌러보기

실제로 쳐서 보내보세요. 상대(엘리)가 잠시 뒤 답합니다 — 흉내(mock)입니다. 서버를 부르지 않습니다.

상태

각 상태가 화면에서 어떻게 다른지 나란히 둔 것입니다.

비어 있음

아직 아무 말도 오가지 않은 처음 모습.

연결됨

왼쪽 위 네모가 초록. 내 말은 오른쪽, 상대 말은 왼쪽.

연결 중

네모가 깜빡입니다. 보내기는 아직 됩니다.

연결 끊김

입력칸을 아예 잠급니다. 칠 수 있게 두면 보내고 나서야 실패를 압니다.

접힘 + 안 읽음

접어둔 동안 들어온 말의 수를 머리줄에 표시합니다.

상대가 입력 중

점 세 개가 순서대로 켜집니다.

정한 규칙

모양을 정할 때 같이 정한 것들입니다.

같은 사람이
연달아 말하면		 이름을 다시 쓰지 않고 말풍선만 잇습니다. 줄마다 이름이 붙으면 정작 내용이 눈에 안 들어옵니다.
위로 올려
읽는 중일 때		 새 말이 와도 화면을 아래로 끌어내리지 않습니다. 대신 새 메시지 ↓ 버튼을 띄웁니다. 읽던 자리를 뺏지 않기 위해서입니다.
내가 보낸 말 항상 맨 아래로 따라갑니다. 방금 내가 한 일의 결과는 보여야 합니다.
연결이 끊기면 입력칸을 잠급니다. 보낼 수 없는 상태에서 글을 치게 두면 헛수고가 됩니다.
연결 상태를
색으로만 알리지 않음		 색 네모 옆에 눈에 안 보이는 글자(연결됨·연결 끊김)를 같이 넣어 화면 읽어주는 프로그램이 읽습니다.
글자 수 200자까지. 입력칸 오른쪽에 0/200 으로 항상 보입니다.
클래스 이름 전부 chat- 으로 시작합니다. 끼워 넣는 페이지에 .field 같은 흔한 이름이 있어도 부딪히지 않습니다.

쓰는 법

어느 페이지든 두 줄 불러오고 mount 한 번이면 끝입니다. 굵게 칠한 자리가 나중에 웹소켓이 들어올 문입니다. 

<link rel="stylesheet" href="chat/chat.css" />
<script src="chat/chat.js"></script>

var 채팅 = Chat.mount('#chatBox', {
  me: '수진',                       // 어느 말이 내 것인지 가르는 기준
  title: '대기실 채팅',
  height: '300px',
  onSend: function (text) {         // 내가 보낼 때 → socket.send(...)
    ...
  }
});

채팅.receive({ from: '엘리', text: '안녕!' });   // 남이 보낼 때 → socket.onmessage 에서
채팅.system('엘리 님이 들어왔습니다');
채팅.setStatus('offline');
채팅.typing('엘리');   채팅.typing(null);
채팅.setMe('새닉네임');
채팅.close();   채팅.open();   채팅.clear();   채팅.destroy();

아직 안 한 것

서버 연결. 채팅은 웹소켓을 쓰게 되는데, 그 명세서 docs/ws-contract.md 가 아직 없습니다. 접속 주소와 메시지 형식을 추측해서 만들면 백엔드가 조금만 달리 만들어도 조용히 어긋납니다. 명세서가 오면 위 코드의 굵은 두 자리만 이으면 되고, 화면은 그대로 둡니다.
